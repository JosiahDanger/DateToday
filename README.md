This branch hosts DateToday 2.0, which is currently in development.

A [FOSS](https://en.wikipedia.org/wiki/Free_and_open-source_software) desktop app for people who want to see the current date and/or time directly on their desktop. Beautiful and lightweight. No bullshit; just quality software.

Features

- Extensive date/time format configuration.
- Customise typeface family, size, weight, text alignment, colour, and shadow.
- Choose one of three gorgeous text rendering modes.
- Drag the widget to any monitor; it will never go off-screen.
- Anchor to your desktop any one of the widget's four corners. If the widget changes in size, the selected corner will remain fixed in place.
- Settings are saved and restored automatically, including where and on which monitor the widget is displayed.
- The app's theme adjusts automatically to that of your operating system.
- Supports high-DPI monitors.
- A [portable application](https://en.wikipedia.org/wiki/Portable_application). Just run the executable; no installation necessary.
- The executable is only 11 MB in size, and occupies about 65 MB of RAM while running.
- The groundwork has been laid for future translation into different languages.

Platform Support

- I perform Windows builds, test them, and distribute them via GitHub.
- I want to do the same for Linux builds in the future.
- I expect that macOS and Linux builds should compile successfully, but I haven't tried.

Privacy

- Absolutely no data-collection whatsoever.
- The app never even attempts to connect to the internet.
- This will never change in the future.

Notice of Minimal AI Use

Before performing any commit, I typically ask an AI chatbot to provide a code review. If it suggests changes, I carefully consider them, and implement them myself if I deem them worthwhile. As such, source code for DateToday is never generated directly by AI. This is not a vibe-coded app.
